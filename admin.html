So kommt es online

  1. Im GitHub-Repo auf Add file → Create new file klicken.
  2. Als Dateinamen hannes/index.html eintippen (der Schrägstrich legt den Ordner an).
  3. Das kopierte HTML einfügen und Commit changes klicken.
  4. Nach ca. einer Minute ist die Seite live. Link verschicken, fertig.
